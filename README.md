💓 VRC-HeartRate-OSC (Python Driver)

A lightweight and intuitive Python application to connect your heart rate monitor (HR) to VRChat via the OSC protocol.

---
📖 Description
This program was created to allow VR users to monitor their heart rate in real time. It can be used in two ways:
1. Standalone: ​​As a simple desktop window to view your BPM while gaming.
2. Avatar Sync: As a driver to send data to your avatar via OSC, using advanced 3-parameter logic.

---

💎 The VRChat Prefab (Paid)
**WARNING:** This software uses a specific data sending logic (division into units, tens, and hundreds).

The system is designed to work exclusively with my Custom Prefab, which allows for smooth and precise heart rate animations on your avatar. The prefab is **not included** in this free repository.

You can purchase it here:
* 🛒 Booth [(https://xvito.booth.pm/)]
* 🛒 Gumroad [(https://xvito.gumroad.com/)

🛠️ OSC Parameters Submitted
* `/avatar/parameters/HR1` (Units)
* `/avatar/parameters/HR2` (Tens)
* `/avatar/parameters/HR3` (Hundreds)

🚀 How to Install and Use
1. Go to the Releases section on the right.
2. Download the `HR_MONITOR.exe` file.
3. Run the executable, select your Bluetooth device, and click Connect.
4. Make sure OSC is enabled in VRChat settings.








💓 VRC-HeartRate-OSC (Python Driver)

Un'applicazione leggera e intuitiva in Python per collegare il tuo cardiofrequenzimetro (HR) a **VRChat** tramite protocollo OSC.

---
📖 Descrizione
Questo programma nasce per permettere agli utenti VR di monitorare il proprio battito cardiaco in tempo reale. Può essere utilizzato in due modi:
1. **Standalone:** Come semplice finestra desktop per vedere i tuoi BPM mentre giochi.
2. **Avatar Sync:** Come driver per inviare i dati all'avatar tramite OSC, utilizzando una logica avanzata a 3 parametri.
